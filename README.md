# # 📄 Interactive PDF-to-HTML Digital Resume

> A pixel-perfect, single-page web resume application that transforms a static PDF document layout into an interactive digital experience. Built using HTML5, CSS3, and Bootstrap 5, the project features a modern dark-mode aesthetic with a centered "Hire Me" call-to-action overlay floating above glassmorphic, blurred content panels (`backdrop-filter: blur`).

# Features Of the Website
# Responsive Gmail and Contact info
* **Design Features:** Glassmorphism UI, Flexbox, Absolute Math Centering
### 🚀 Tech Stack
# Technologies Used
* **Frontend:** HTML5, CSS3, Bootstrap 5 (via CDN)
